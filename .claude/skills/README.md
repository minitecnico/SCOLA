# Habilidades do Claude Code neste projeto

Origem: [mattpocock/skills](https://github.com/mattpocock/skills) (licença MIT, ver `LICENSE-mattpocock-skills`), versão `d81f3a1`.
São as mesmas habilidades que o plugin oficial `mattpocock-skills` distribui. Ficam aqui como arquivos do projeto, para o Claude Code usar ao trabalhar no SCOLA (não fazem parte do sistema que roda no ar).

Antes de usar as de tickets e triagem (`/to-spec`, `/to-tickets`, `/triage`, `/wayfinder`), rode uma vez `/setup-matt-pocock-skills`.
Atualizar: copiar de novo as pastas listadas em `.claude-plugin/plugin.json` do repositório de origem.
