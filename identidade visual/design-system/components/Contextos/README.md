# Contextos

Página de teste que mostra a marca SCOLA nos sete lugares reais onde ela precisa funcionar; confira aqui toda mudança de logo ou cor antes de aprovar.

- **Menu lateral:** fundo `preto`, `scola-horizontal-compacta-negativa.svg` a 36px de altura; item ativo com fundo `amarelo` e texto `preto`.
- **Login:** painel `preto` com `scola-horizontal-negativa.svg` e o símbolo gigante a 6% de opacidade; formulário sobre `branco`, botão `preto`.
- **Barra superior no celular:** fundo `preto`, compacta negativa a 32px.
- **Aba do navegador:** `favicon.svg` a 16px ao lado de outras abas.
- **Tela inicial:** `icon-192.png` entre outros apps.
- **Boletim P&B:** `scola-mono-preta.svg` no rodapé, ao lado de "Documento gerado por SCOLA".
- **WhatsApp:** `og-image.png` como prévia do link.

Não é um componente para importar: é uma bancada de teste. Nomes, notas e endereços são de exemplo.
