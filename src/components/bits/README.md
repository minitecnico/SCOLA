| Componente | Onde | Ajuste |
|---|---|---|
| CountUp | números dos cartões (`StatCard`) | formato brasileiro; respeita "reduzir movimento" |
| BlurText | "Como posso ajudar?" da página IA | `as="h1"` |
| ShinyText | "Pensando…" da IA | — |

Ficaram de fora os efeitos com three.js/WebGL, cursores e fundos animados, que são pesados para computadores de escola e celulares.
Para trazer outro componente: copie a pasta de `src/ts-tailwind/<Categoria>/<Nome>` do repositório e registre aqui.
